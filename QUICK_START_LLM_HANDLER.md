## For Developers

### Using the New System

**Before (old way - deprecated):**
```python

```

**After (new way - recommended):**
```python
result = await formatter.generate_recap(summary, style, persona)

for warning in result.warnings:
    logger.warning(f"Recap generation warning: {warning}")

# Check if circuit breaker is open
if result.mode == RecapMode.CIRCUIT_OPEN:
    # Send alert to ops team

```

### Adding LLM Calls in New Code

```python
from ai_text.text_formatter import TextFormatter
from ai_text.llm_handler import RecapMode
import logging

logger = logging.getLogger(__name__)

async def my_new_recap_function(summary):
    formatter = TextFormatter()

    # Generate with robust error handling
    result = await formatter.generate_recap(
        summary=summary,
        style="standard",
        persona="witty",
        provider="openai"  # or "anthropic"
    )

    # Log metadata for monitoring
    logger.info(
        "Recap generated",
        extra={
            "mode": result.mode.value,
            "provider": result.provider,
            "latency_ms": result.latency_ms,
        }
    )

    # Log warnings
    if result.warnings:
        for warning in result.warnings:
            logger.warning(f"Warning: {warning}")

    # Inform users if circuit is open
    if result.mode == RecapMode.CIRCUIT_OPEN:
        text = "⚠️ AI temporarily unavailable:\n\n" + result.text
    else:
        text = result.text

    return text
```

### Understanding RecapResult

```python
@dataclass
class RecapResult:
    text: str                # The generated recap
    mode: RecapMode          # "llm" | "deterministic" | "circuit_open"
    warnings: List[str]      # Any warnings to log
    provider: Optional[str]  # "openai" | "anthropic" | None
    latency_ms: Optional[int] # Response time
```

**Mode meanings:**
- `llm`: Successfully generated by LLM
- `deterministic`: Used fallback (LLM failed or not configured)
- `circuit_open`: Circuit breaker is open, using fallback

## For Operators

### Monitoring Endpoint

```bash
GET /monitoring/llm-circuit-status
```

Returns circuit breaker health for both providers.

### What to Monitor

1. **Circuit breaker opens** - Should be rare (0 per day)
2. **Mode distribution** - Should be >95% LLM
3. **Latency** - Should be <5s for P95
4. **Error rate** - Should be <5%

### Log Analysis

```bash
# Find circuit breaker opens
grep "Circuit breaker OPENED" logs.txt

# Track success rate
grep "llm_mode" logs.txt | grep "success" | wc -l
grep "llm_mode" logs.txt | grep "failed" | wc -l

# Find recent errors
grep "LLM call failed" logs.txt | tail -20
```

### Troubleshooting

**Circuit breaker stuck open?**
1. Check API keys in environment variables
2. Verify provider status (OpenAI/Anthropic)
3. Review recent errors in logs
4. Wait for auto-recovery (30 min) or restart service

**High error rate?**
1. Check rate limits on API plan
2. Verify network connectivity
3. Review error types in logs
4. Consider switching providers

**Slow responses?**
1. Check provider API status
2. Monitor network latency
3. Consider reducing timeout if consistently timing out

## Common Patterns

### Pattern 1: Log Everything
```python
result = await formatter.generate_recap(...)

logger.info(
    "Recap generated",
    extra={
        "mode": result.mode.value,
        "provider": result.provider,
        "latency_ms": result.latency_ms,
    }
)

for warning in result.warnings:
    logger.warning(warning)
```

### Pattern 2: User Notification on Circuit Open
```python
result = await formatter.generate_recap(...)

if result.mode == RecapMode.CIRCUIT_OPEN:
    text = "⚠️ AI temporarily unavailable, showing standard recap:\n\n" + result.text
else:
    text = result.text

return text
```

### Pattern 3: Alerting
```python
result = await formatter.generate_recap(...)

if result.mode == RecapMode.CIRCUIT_OPEN:
    send_alert_to_slack("LLM circuit breaker is open")
```
